# Java Terminal Games

A collection of minimal, text-based interactive games written in Java that run directly in your terminal.


## 1. Detective Who
A choice-driven noir mystery game where your deductive skills decide the case.

**Description**: A high-profile crime has occurred. As the detective, you must search rooms, inspect evidence, and interrogate suspects. Your final choices determine if you catch the real culprit or fail the investigation.

**Key Features**: Branching storyline paths, interactive dialogue options, and multiple distinct endings.


## 2. Red Light, Green Light
A suspenseful timing game inspired by the classic childhood challenge.

**Description**: You have 40 seconds to move 10 steps forward. You must type y (yes) to move when the light is GREEN. If you type y when the light is RED, you are instantly eliminated.

**Key Features**: Live visual progress bar, terminal colors, and a strict 3-second round timer.
